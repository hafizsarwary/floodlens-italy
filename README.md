# FloodLens Italy

FloodLens Italy is an open-source WebGIS project for exploring flood exposure in Italian municipalities.

The project answers a simple question:

> If flooding happens here, what is exposed?

The tool combines open flood hazard data, building footprints, roads, and critical services to calculate and visualize exposure indicators such as:

- buildings exposed to flood hazard zones
- roads affected
- schools and hospitals exposed
- population or urban-area exposure proxy
- simple explainable exposure score

## Project goals

1. Build a clean flood exposure analysis workflow using open data.
2. Transform complex spatial datasets into simple, practical insights.
3. Create an interactive WebGIS dashboard suitable for decision support.
4. Demonstrate skills in GeoAI, Earth Observation, spatial analysis, and WebGIS.

## Study area

The first prototype will focus on one Italian municipality or flood-prone area.  
The final study area will be selected based on data availability and relevance.

## Planned data sources

- ISPRA / IdroGEO flood hazard data
- OpenStreetMap buildings, roads, and points of interest
- Copernicus or other open Earth Observation data if needed
- Italian open administrative boundaries
